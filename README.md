# CheckBrblImage 板厚图片确认工具

逐个确认板厚测量图片是否异常，把无异常的测量数据发送到板厚分析电脑的待处理文件夹。

## 数据来源与命名规则

监控 `ImagesFolder` 下的 `型号_工单` 目录，其下每个测量数据文件夹命名为：

```
型号_工单_测量时间(14位)_二维码_板厚
Q16132123A6_000030902370_20261120050334_3090237031_2.7mm
```

二维码字段可能为空（未读取到二维码），此时形如 `..._20261120050744__2.7mm`（中间连续两个下划线）。

## 主界面说明

左侧表格三列：`二维码`、`板厚图片`（缩略图状态）、`确认结果`。

### 二维码单元格标红

以下情况该单元格显示红底白字（鼠标悬停可看到具体原因）：

| 情况 | 说明 |
| --- | --- |
| 二维码为空 | 未读取到二维码，需要人工指定或删除后重测 |
| 格式异常 | 二维码不是 10 位数字（历史遗留数据），不支持手动修改，只能核对或标记删除后重测 |
| 二维码重复 | 当前所选型号内存在多块相同二维码（全部标红） |
| 人工指定过 | 手动补录的二维码，确认后仍保持红色以便复核 |

已标记为「删除当前异常图片」(❌) 的记录视为已排除的异常数据，**不再标红**，
也不参与重复判定和底部统计。

### 双击手动指定二维码

双击**二维码为空**的那一行二维码单元格：

1. 弹窗输入 10 位数字二维码；
2. 非 10 位数字、或与当前型号下已有二维码重复，都会提示并重新输入；
3. 校验通过后，**测量数据文件夹会改名**（补上二维码字段），缩略图文件名同步改名，
   下游板厚分析即可按正常命名读取。

二维码非空的行双击不响应；其中二维码格式异常的行会提示“不支持手动修改，
请标记删除后重测”。

### 底部状态栏

```
已测量 N 块，其中有效数据 M 块，未读取到二维码 K 块。
```

统计只计**未标记删除**的记录：

- 已测量：当前型号表格中未标记删除的记录数
- 有效数据：二维码非空且不重复的记录数（格式异常但非空、唯一的也计入）
- 未读取到二维码：二维码为空的记录数

重复判定同样只在未标记删除的记录之间进行。

### 发送前防呆

点击「发送到板厚分析」时，只要存在**二维码为空、且未人工指定、也未标记为删除**的记录，
就弹窗提示「二维码缺失」并列出这些记录，不允许发送。处理办法二选一：

- 双击该行二维码单元格手动指定二维码；
- 确认是异常图片，点「删除当前异常图片」后重测。

## 其他行为

- 无异常图片点「✅ 标记为 OK 板」，异常图片点「❌ 删除当前异常图片」；
- 所有图片确认后点「发送到板厚分析」，后台线程逐个移动文件夹，
  被占用导致失败的文件夹会汇总提示，可重试；
- 缩略图由监控线程自动拼接生成（`H/C1..C4` 交替拼接），生成期间该行状态为空白。

## 配置

同目录 `config.json`：

```json
{
    "ImagesFolder": "D:\\PCBImages",
    "ThumbnailFolder": "Z:\\PCBImages",
    "ProcessFolder": "D:\\PCBThickness"
}
```

三个目录必须存在，否则启动时提示并退出。

## 运行与打包

```bat
uv run python CheckBrblImage.py
compile.bat            :: pyinstaller 打包到 dist\CheckBrblImage
```
